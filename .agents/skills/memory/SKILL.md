# Reglas de memoria

1. Al empezar, lee `MEMORY.md` en la raíz del proyecto. ( en caso de que no este creado crealo para almancenar la informacion del proyecto)
2. Al terminar un cambio relevante, actualiza `MEMORY.md`: estado actual, decisiones, aprendizajes y próximos pasos.
3. Máximo ~50 líneas: resume o elimina lo que ya no aporte.
4. No toques este archivo para guardar datos del proyecto.
